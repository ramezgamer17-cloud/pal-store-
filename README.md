Welcome to **Pal Store**, a responsive e-commerce web application designed for browsing, searching, filtering, and managing smartphone purchases online.

---

## 📌 Project Overview
**Pal Store** provides a streamlined user interface for viewing top mobile phone brands, inspecting specifications, adding items to a real-time shopping cart, and filtering products dynamically without page reloads.

---

## ✨ Key Features
* 🔍 **Live Search & Filter**: Instant product lookup by name and brand filtering (Samsung, Apple, Huawei, Xiaomi, Honor, RedMagic).
* 🛒 **Dynamic Interactive Cart**: Live counter updates, total price calculation, and cart item management via JavaScript DOM manipulation.
* 📱 **Fully Responsive Layout**: Built with modern CSS Grid and Flexbox for seamless display on desktops, tablets, and mobile phones.
* ❓ **Interactive FAQ Page**: Dynamic collapsible accordion layout for customer support and common questions.
* 💼 **Sell & Career Forms**: Dedicated views allowing users to submit used devices or apply for store positions.
